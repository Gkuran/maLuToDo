# Audio local

O app usa somente as faixas cadastradas em `TRACKS`, no arquivo `app.js`.
Ele sorteia uma faixa ao abrir e passa automaticamente para outra quando a musica termina.

Faixas atuais:

- `Ghost - Mary On A Cross.mp3`
- `Leonard Cohen - Famous Blue Raincoat.mp3`

Nao existe upload nem escolha manual de audio na interface. Para trocar ou adicionar musicas no futuro, coloque o arquivo `.mp3` nesta pasta e atualize a lista `TRACKS`.
